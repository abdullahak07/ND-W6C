# COMP6013 Week 6 — Student Interactive Website

Final student-facing site covering Web security, TLS, HTTPS and SSH.

## Run locally
```bash
npm install
npm run dev
```

## Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Theme
Modern light secure-network theme. The learning website is light and refreshing; only the embedded games use an 8-bit console aesthetic.
